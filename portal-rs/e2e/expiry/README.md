# Expiry qualification

This lane covers time-bound portal behavior for [Oteryn Platform #2002](https://github.com/Oteryn/Oteryn-Platform/issues/2002). It inherits the shared Playwright projects for Polish and English at 1440 and 390 pixels. Run it from `portal-rs/e2e` with the prerequisites in the [browser harness README](../README.md) and [environment reference](../ENVIRONMENT.md). The expiry launcher also needs Node 22.15+ for process replacement.

```sh
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm ci --ignore-scripts --cache /tmp/portal-browser-npm
# Set PORTAL_E2E_ADMIN_DATABASE_URL privately to the disposable local PostgreSQL administrator URL.
# Set PORTAL_E2E_BINARY to the absolute path of the built debug/oteryn-portal binary.
node expiry/launch.mjs
```

In a second shell, set `EXPIRY_SCRATCH` to the scratch directory printed by the launcher. Import `$EXPIRY_SCRATCH/ca.pem` as a trusted HTTPS CA into the test Chromium user's certificate store and remove it after the run. On Linux, Chromium uses an NSS database, typically `~/.local/share/pki/nssdb` or the legacy `~/.pki/nssdb` when present. Pass the same CA to Node for Playwright's HTTP requests.

```sh
NODE_EXTRA_CA_CERTS="$EXPIRY_SCRATCH/ca.pem" CHROMIUM_PATH=/usr/bin/chromium \
  node run.mjs "$EXPIRY_SCRATCH/env.json" test -c expiry/playwright.config.mjs
```

The launcher delegates to `local.mjs` and its `harness.mjs` child. It adds a test-only native OAuth client to the configured allowlist, a disposable private admission service bearer and one sandbox coin package. The account and native OAuth client are provisioned through the portal seed CLI. Playwright writes its detailed result to `expiry/test-results/expiry.json`. Keep the scratch environment, mail, browser traces and reports private. The launcher selects the supported closure disposition `hold` so that the grace test measures Platform worker command issuance independently of any Game receipt.

The running portal has no controllable clock for these flows. The suite moves only timestamp fields on its own persisted fixtures and makes real requests to the portal. A five-second margin accommodates I/O before the deadline, and the expired case places the deadline one second in the past. Cleanup jobs are enqueued through the real worker's outbox and checked for successful processing. The registration, login and OAuth helpers poll actual shared request budgets before setting near-term deadlines. OAuth authorize and exchange share the login source budget. ## Product and authority gaps

- Staff invitations have no issuance or acceptance lifecycle in the composed portal. The capability matrix tracks `feat-staff-invite`. [PANELS_CAPABILITY_MATRIX.md:56](../../../docs/architecture/PANELS_CAPABILITY_MATRIX.md#L56)
- The appeal workflow is domain-only for the player and has no timed appeal deadline. The capability matrix tracks `feat-appeals-route`. [support/src/appeals.rs:284](../../crates/support/src/appeals.rs#L284), [support/src/appeals.rs:327](../../crates/support/src/appeals.rs#L327), [PANELS_CAPABILITY_MATRIX.md:131](../../../docs/architecture/PANELS_CAPABILITY_MATRIX.md#L131)
- The separate admin-control request-bound TOTP proof lasts 300 s. Approval first needs an R4 preview derived from a successful stored Game dry run. The suite covers the browser sudo deadline and leaves that approval path unqualified. [admin/src/control/integration.rs:73](../../crates/admin/src/control/integration.rs#L73), [admin/src/control/integration.rs:125](../../crates/admin/src/control/integration.rs#L125), [admin/src/control/integration.rs:161](../../crates/admin/src/control/integration.rs#L161)
- Signed admission grants default to 20 s with a 5–30 s range. Qualification of an issued grant's expiry needs the accepted native Game authorities, a live candidate route and the admission signer. This lane reaches the real authority refusal and leaves successful grant issuance unqualified. [gameauth/src/admission/grant.rs:22](../../crates/gameauth/src/admission/grant.rs#L22), [gameauth/src/admission/grant.rs:40](../../crates/gameauth/src/admission/grant.rs#L40), [gameauth/src/admission/tickets.rs:168](../../crates/gameauth/src/admission/tickets.rs#L168), [gameauth/src/admission/wire.rs:386](../../crates/gameauth/src/admission/wire.rs#L386)
- Wallet and coin reversal holds have no time deadline. Staff release and wallet settlement are explicit operations.
