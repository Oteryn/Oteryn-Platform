# Wybierz profesję

Otwórz [szablon sekcji](index.html) w przeglądarce i wybierz **Styl ilustracji**. Pole „Most” pokazuje postacie w izometrycznych sceneriach, a „Bonelord” — malarskie portrety. Zmiana stylu zachowuje wybraną profesję. Szablon działa lokalnie bez serwera i kompilacji.

| Zestaw | Plansza porównawcza | Portrety do podmiany |
| --- | --- | --- |
| Most (domyślny) | [Zobacz planszę](most/plansza.png) | [Katalog most](most/) |
| Bonelord | [Zobacz planszę](bonelord/plansza.png) | [Katalog bonelord](bonelord/) |

Aby zmienić jedną ilustrację, podmień odpowiedni plik WebP w katalogu zestawu i odśwież podgląd. Oba katalogi używają tych samych nazw: `rycerz.webp`, `paladyn.webp`, `druid.webp`, `czarodziej.webp` i `mnich.webp`. Zachowaj pionowe proporcje dotychczasowego portretu i umieść twarz w górnej połowie kadru.

Plik `plansza.png` w każdym zestawie jest zapisanym podglądem pierwotnej propozycji. Po zmianie portretów bieżący wygląd pokazuje szablon HTML. W polu **Styl ilustracji** atrybut `selected` ustala domyślny zestaw przy kolejnym otwarciu pliku.
