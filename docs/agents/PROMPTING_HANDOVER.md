# Platform Prompt Handover

Use this file only when preparing a Platform worker prompt or handing a Platform task to another worker.

1. Resolve the META binding and use its prompting standard.
2. Read the live governing Issue/PR and the nearest instructions for the paths involved.
3. State the observable result, writable scope, Platform-specific constraints, current locators and acceptance delta.
4. Keep external/server repositories, production, protected environments, credentials and live payments outside scope unless separately authorized.
5. Preserve only material completed work, evidence, remaining risk and one concrete next action.
6. Verify that the prompt does not copy the organization operating model or present stale task state as current authority.

Owner-facing advice is Polish unless requested otherwise. The worker prompt may use concise English. Do not ask the owner for a current fact that an authorized read can resolve.
